# くちぱく（kuchipaku-llm）

口パク（無声）の唇の形から日本語を入力する研究プロトタイプです。段階を分けて、前の段階が測定で確かめられてから次に進みます。

- デモ: https://eisuke29.github.io/kuchipaku-llm/ （Chromeで開き、カメラを許可）

## 段階

1. **母音を確実に打つ（いまここ）**: 母音の口の形をキープ → 口を閉じる、で1文字。「文字・閉口・文字・閉口」の順に、5母音を正確に入力できるようにする
2. **閉口なしの連続入力**: 口を止めずに話しても、同じ母音の重なり（「いい」「ええ」など）やモーラ数をLLMで判断する
3. **文脈で文字列を推定**: 母音列から日本語の候補を出し、クリックで選ぶ

## 第1段階の仕組み

- **口形の登録（必須）**: カメラを始めると、5母音と閉じた口を3周ずつ、周ごとに順番を変えて登録します。登録後、周ごとの交差検証で母音ごとの正答率を表示し、低い母音だけ撮り直せます。声を出したときと口パクでは口の動きが違うため、使うときと同じ口パクで登録します
- **特徴量**: MediaPipe Face Landmarker の3Dランドマークを、両頬・額・顎から作った顔の座標系に変換して測ります（頭の向きや距離の影響を除くため）。口腔の面積・縦横比、内外の唇の高さと幅、唇中央の突き出し、唇の厚み、口角の高さ、顎の開きに、ブレンドシェイプを加えています
- **判定**: 本人の登録データで標準化したk近傍法。どの登録データからも遠い形（口の移り変わり中など）は「不明」として使いません
- **確定**: 母音の形を一定時間キープすると準備完了（緑）、口を閉じると確定。Backspaceで全部消します
- **測定**: 設定の「精度テスト」でお題の母音を10問打ち、正答率と1文字あたりの時間を測ります。「記録を書き出す」で登録データ・交差検証・テスト結果をJSONで保存できます

## ファイル

- `index.html`: 第1段階のデモ
- `core.js`: 第2・3段階用（読み→口形の変換、照合、LLMへの指示）
- `research.md`: 先行研究・新規性・学会戦略のまとめ
