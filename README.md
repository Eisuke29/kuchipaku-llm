# 口パク母音入力 × LLM（kuchipaku-llm）

口を止めずに無声で話すと、唇の形から母音の並びを読み取り、LLMが文脈から日本語の候補を出します。候補をタップしていくと文ができます。

- デモ: https://eisuke29.github.io/kuchipaku-llm/ （Chromeで開き、カメラを許可）
- カメラなしでも、画面の母音キーやキーボードの a i u e o n で試せます

## 使い方

1. 右上の設定に Gemini APIキーを入れる（[Google AI Studio](https://aistudio.google.com/) で無料で作れます）。キーはブラウザにだけ保存され、このリポジトリには入りません
2. 「カメラを開始」を押す。口元だけが自動で追従・切り抜かれ、グレースケールで表示されます
3. 唇を軽く閉じて1秒ほど待ってから、口を止めずに無声で話す。唇を閉じて0.7秒止まると区切られ、候補が出る
4. 候補をタップ（数字キー1〜9でも可）すると文に追加され、次の区間に進む

口形の登録は任意です。登録しなくても既定の判定で動きます。精度を上げたいときは「口形を登録」で、画面の案内に沿って6つの口形を3周ずつ登録してください。

「相手のメッセージ」欄に返信元の文を入れると、文脈で候補が当たりやすくなります。

## 仕組み

1. **口形認識:** MediaPipe Face Landmarker（学習済みの顔モデル）が出す口のブレンドシェイプと唇の開き・幅から、6クラス（あ・い・う・え・お・閉）を判定します。登録がなければ経験則による既定の判定、登録すれば本人のデータとの近さで判定します
2. **連続分節:** 口を止めずに話しても、口形が変わるごとに区間を切ります。区間の長さと、2番目に近かった口形（う↔お など）も記録します
3. **LLMで候補生成:** 区間の並び、長さ、確定済みの文、相手のメッセージをLLMに渡し、モーラ数の推定も含めて候補を出させます
4. **口形で照合:** 候補の読みを口形の並びに変換して観測と照らし合わせ、並べ替えます。合う候補が1つもないときは、ずれを伝えて1回だけ推定し直させます
5. **タップで逐次確定:** 確定した文が次の推定の文脈になります

LLMは Gemini API（無料枠）を使い、上限に当たると予備モデル（既定は gemini-2.5-flash-lite）に切り替えます。

## 注意

- Gemini API の無料枠に送った内容は Google の製品改善に使われます。被験者実験ではローカルLLMか有料枠を使ってください
- 口形の登録データはブラウザに保存されます

## ファイル

- `index.html`: デモ本体
- `core.js`: 読み→口形の変換、照合、プロンプト（Node.jsからも読み込めます）
- `research.md`: 先行研究・新規性・学会戦略のまとめ
